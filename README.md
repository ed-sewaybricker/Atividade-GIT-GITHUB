# Agentes do Valorant

Projeto desenvolvido para a atividade prática de Git e GitHub.

## Objetivo

Criar uma página web utilizando HTML, CSS e JavaScript para apresentar agentes do Valorant em formato de cards interativos.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Exibição de agentes em cards
- Estilização personalizada
- Interação com botões
- Reprodução de áudio dos agentes ao selecionar

## Estrutura do Projeto

```plaintext
index.html
style.css
script.js
/audio
```

## Conceitos de Git e GitHub Utilizados

- Commits organizados
- Branches
- Pull Requests
- Issues
- Merge entre branches
